# Análise de Dados com SQL - Base Sakila

Este repositório contém uma coleção de consultas SQL desenvolvidas sobre a base de dados Sakila (MySQL). O objetivo é documentar a prática de comandos essenciais e técnicas para extração e análise de dados.

## Estrutura do Repositório

```text
sql-analise-sakila/
├── dataset/                  # Instruções para obtenção e importação da base
├── queries/
│   ├── basico/       # Consultas de fundamentos
│   ├── intermediario/ # Consultas com junções e agregações
│   └── avancado/     # Consultas com Window Functions, CTEs e Views
└── README.md
