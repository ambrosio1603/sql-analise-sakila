# Obtenção da Base de Dados

Para reproduzir as análises deste projeto, foi utilizada a base de dados de exemplo Sakila, disponibilizada oficialmente pelo MySQL.

## Passos para Importação

1. Acesse a página oficial de bases de exemplo do MySQL: https://dev.mysql.com/doc/index-other.html
2. Localize a seção "Example Databases" e baixe o arquivo "sakila-db.zip".
3. Descompacte o arquivo em uma pasta de sua preferência.
4. Abra o MySQL Workbench e conecte-se ao seu servidor local.
5. Execute o script "sakila-schema.sql" para criar a estrutura das tabelas.
6. Execute o script "sakila-data.sql" para popular o banco de dados com os registros.
7. As consultas deste repositório foram desenvolvidas e testadas no MySQL Workbench 8.0.
